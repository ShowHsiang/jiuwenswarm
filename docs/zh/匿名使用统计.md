# 匿名使用统计

JiuwenSwarm 在有效的顶层程序启动后发送一条匿名启动事件，用于统计日活、启动次数和版本分布。统计适用于源码运行、PyPI 安装以及 exe/dmg 桌面版本。

## 收集范围

发送的数据仅包括：随机生成的安装标识、启动事件标识、JiuwenSwarm 版本、操作系统与 CPU 架构、分发方式、启动入口、启动时间和时区，以及根据系统 IANA 时区（必要时回退到系统区域设置）离线推导的粗粒度区域和 ISO 两位国家/地区代码。该推导不会请求第三方定位服务，也不采集经纬度。

### 字段说明

| 字段 | 示例 | 含义 |
| --- | --- | --- |
| `schema_version` | `1` | 上报数据结构版本，用于后端兼容不同版本的客户端。 |
| `event_id` | `7e678f36-bd02-4acd-b7ad-e0ae8332ad64` | 本次启动事件的唯一 UUID。每次启动都会生成新值，后端用它避免网络重试造成重复计数。 |
| `installation_id` | `867c012b-0770-457e-861f-6ea421abd448` | 当前 JiuwenSwarm 安装实例的匿名 UUID。同一安装实例长期保持不变，用于计算 DAU；不来源于硬件信息。 |
| `product` | `jiuwenswarm` | 产品名称，方便后端区分不同产品。 |
| `event` | `app_launch` | 事件类型，表示应用启动。 |
| `occurred_at` | `2026-08-20T10:30:00+08:00` | 客户端实际启动时间，包含 UTC 时区偏移。 |
| `timezone` | `Asia/Singapore` | 系统使用的 IANA 时区。 |
| `region` | `Asia Pacific` | 根据系统时区和区域设置离线推导的粗粒度地区，如亚太、欧洲、北美。 |
| `country` | `SG` | 推导出的 ISO 3166-1 两位国家或地区代码，例如 `CN`、`SG`、`US`。 |
| `version` | `0.2.4.beta4` | 当前 JiuwenSwarm 版本，用于统计版本分布。 |
| `os` | `Windows 11` | 操作系统及主要版本。 |
| `arch` | `x64` | CPU/系统架构，常见值为 `x64`、`arm64`。 |
| `distribution` | `source` | 软件分发方式：`source` 表示源码运行、`pypi` 表示包安装、`exe` 表示 Windows 程序、`dmg` 表示 macOS 程序、`bundle` 表示其他打包版本。 |
| `entrypoint` | `cli` | 用户启动入口：`cli` 命令行、`desktop` 桌面端、`tui` 终端界面、`start_services` 服务启动器、`app` 后端组合启动入口。 |

每次启动都会产生一个新的 `event_id`，而同一安装实例会继续使用相同的 `installation_id`。例如，同一安装实例当天启动 5 次时，DAU 计为 1，`launch_count` 计为 5。

不会收集用户账号、用户名、主机名、MAC 地址、硬盘序列号、IP 地址字段、项目路径、提示词、对话内容或生成内容。服务端可能像普通 Web 服务一样在网络访问日志中短期看到来源 IP，但该信息不会写入启动事件表。

安装标识保存在 `~/.jiuwenswarm/telemetry/state.json`，由随机 UUID 生成，不来源于硬件信息。升级或切换 JiuwenSwarm 安装方式时，该标识保持不变。

每次有效启动都会生成不同的事件标识。发送失败的事件保存在本地队列中，并在后续启动时重试；服务端使用事件标识去重，因此网络重试不会增加启动次数。桌面版内部的 Web、Gateway 和 AgentServer 子进程不会作为独立启动上报。

## 关闭统计

启动前设置以下环境变量即可完全关闭事件创建、保存和发送：

```text
JIUWENSWARM_TELEMETRY_DISABLED=1
```

开发或私有部署可以使用以下变量替换接收地址：

```text
JIUWENSWARM_TELEMETRY_URL=https://monitor.example.com/v1/launches
```

自签名证书仅可在测试时通过以下变量临时跳过校验：

```text
JIUWENSWARM_TELEMETRY_INSECURE_TLS=1
```

该开关只影响日活上报请求。正式环境不得启用；必须使用受信任的 HTTPS 证书。
